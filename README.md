# Projet 3 — Requêtez une base de données avec SQL

## Présentation du projet

Ce projet, réalisé dans le cadre de ma formation de Data Analyst, a pour objectif de mettre en pratique SQL pour interroger une base de données, extraire les informations pertinentes et répondre à des besoins d'analyse.

Il s'inscrit dans une démarche d'analyse de données visant à transformer des données stockées dans une base relationnelle en informations exploitables.

Au-delà de la rédaction de requêtes, ce travail comprend une documentation technique et méthodologique permettant de présenter la démarche suivie et de faciliter la compréhension des traitements réalisés.

## Objectifs

- Comprendre la structure d'une base de données et identifier les informations nécessaires à l'analyse.
- Formuler des requêtes SQL adaptées aux besoins identifiés.
- Extraire et organiser les données pertinentes.
- Structurer une démarche de travail documentée et reproductible.
- Présenter les travaux réalisés dans une documentation claire.
